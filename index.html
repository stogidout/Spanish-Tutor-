Key rules

  • Days and months are not capitalized in Spanish.
  • The week starts on Monday (lunes).
  • Dates go day before month: el 5 de noviembre.
  • The 1st is el primero (not el uno).
  • el lunes = on Monday; los lunes = on Mondays.

How to say a date

  1. Start with Hoy es el (“Today is the…”)
  2. Add the number — primero for the 1st; otherwise the plain number
  3. Add de + the month → Hoy es el veinte de abril.

Tricky sounds

  • j sounds like English h: junio (HOO-nyoh), julio (HOO-lyoh), jueves (HWEH-vehs).
  • Accent marks show stress: miércoles, sábado.
  • ñ sounds like ny: mañana, cumpleaños. ll is often like English y.
